SISTEMA ESCOLAR MVC

1. Copiar la carpeta crudfix a C:\xampp\htdocs\
2. Iniciar Apache y MySQL en XAMPP.
3. Importar database/crud_mvc.sql en phpMyAdmin.
4. Abrir http://localhost/crudfix/

Módulos: Inicio, Estudiantes, Materias, Docentes y Horarios.
Estudiantes conserva su CRUD original y ahora es compatible con el enrutador MVC principal.
